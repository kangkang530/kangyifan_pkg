    上车体总布置概述¶

    概述¶

    1.1 什么是总布置¶

    总布置（Layout / Vehicle Packaging）是把整车各系统——动力总成、底盘、车身、内外饰、电气——在 **统一的整车坐标系**内"摆得下、摆得对、摆得合理"的设计活动。它不是画一张图，而是用一套可控的 **基准 + 尺寸 + 规则**去约束全车的几何关系。
    整车的总布置设计过程是设计硬点（Hard Point）和设计控制规则逐步明确、不断确定的过程。 设计硬点是确定车身、底盘与零部件相互关系的基准点、线、面及控制结构和参数的统称， 主要分为：整车装备选型硬点、安装装配硬点（ASH，含尺寸与型式硬点）、轮廓硬点、 运动硬点（MTH）及性能硬点等。 后续的设计工作必须以确定的设计硬点为基础展开

    上车体范围界定¶

    要点¶

    "上车体"是相对"下车体（底盘、机舱、地板下结构）"划分的车身总成大区。H20 上车体技术方案明确了其构成：

    上车体系统构成：主要由侧围焊接总成（左）、侧围焊接总成（右）、顶盖焊接总成组成。

    因此"上车体总布置"的工作对象是：侧围（A/B/C/D 柱、门洞、门槛、后轮罩、后侧围）+ 顶盖 （顶盖本体、撑条、前后横梁、天窗加强环） 所围成的乘员舱空间边界，以及这个边界与以下要素的 匹配关系：

    • 人（R 点/H 点、坐姿关节角、头部包络、眼椭圆、上下车通道）
    • 内外造型（外表面、分缝线、棱线、腰线、侧围外板面型）
    • 内外饰与附件（仪表板、门护板、座椅、安全带、天窗、顶棚、后视镜、把手、灯具）
    • 运动件与结构（车门开闭、车窗运动、顶盖与侧围的焊接搭接层次）

    示例¶

    从**总布置校核**的角度，上车体可划分为四类待校核区域，每一类都由一组断面表达：

    区域 校核内容 依据
    门洞与门槛 门洞法兰面参数（L1 = 1 mm 控制边缘线落差、L2 = 15–18 mm 法兰面宽度、R1 = 3–6 mm 圆角、α > 4° 斜角）；前门门框与 B 柱间隙 > 8 mm SJ 4-2008 §4.1.3、§4.2.2
    侧围与立柱 A/B/C 柱饰板的间隙体系与 B 柱侧碰断面系数；立柱内饰板与玻璃 2.5–3 mm、与安全带 > 5 mm、与座椅 > 40 mm SJ 20-2008 §5.4、SJ 54-2009
    顶盖与顶棚 顶篷与玻璃 2.5–3.0 mm、与顶盖横梁 0 ~ −0.5 mm、与侧围边梁 8–15 mm（考虑侧碰 ≥ 25 mm）；天窗翻边 3/6/15 mm SJ 18-2008 §5.3
    后侧围与后轮罩 后轮包络面与轮罩、翼子板间隙（按独立/非独立后悬工况制作） SJ 51-2009 §4.2

    注意事项¶

    • 与车身（白车身）的边界：总布置输出**边界与硬点**（坐标系、RPS 定位、断面、间隙），车身负责**结构实现**。H20 的"整车设计基准"四条定义（右手坐标系与 CATIA part 绝对坐标系重合；高度取前纵梁下平面平直段上正下负；宽度取纵向对称中心线左负右正；长度取整备质量状态下前轮中心铅垂线前负后正）是这条边界的**接口协议**。
    • 与内外饰的边界：总布置/SEG 输出**间隙、段差、圆角定义**（SJ 45-2009 §6.3：外观可见特征由工程定义、经造型师确认后发布），内外饰负责零件结构与工艺（各分系统指导书：SJ 18/20/21/24/46/47）。
    • 与电气的边界：存在**必须协同**的耦合项——组合仪表防眩目的"椭圆双焦点"设计需要电气提供仪表发光面位置，SJ 46-2009 §6.1 明确"此设计要与电气工程师相互协助设计"。
    • 与造型的边界：SEG 阶段的立场是"工程应尽可能去满足造型的要求"（SJ 40-2009 §4），通过断面与数据反馈可行性，而非直接否决。
    • 容易混淆之处：内饰件的"内部结构"边界不同——SJ 47-2009 §6.3 明确"烟灰缸……内部结构一般**供应商设计**"，这类"边界内委托"的情况需在接口定义时写清楚。

    核心目标¶

    要点¶

    目标维度 具体内涵（来自知识库）
    空间与舒适性 前排/中排按 SAE 95% 人体、三排按 SAE 50% 人体 布置校核；头部空间、肩/臀/肘/腿部空间满足目标值
    法规符合性 视野、凸出物、安全带固定点、灯具、号牌板、外廓尺寸等全部法规项可校核
    性能 整车碰撞安全满足 C-NCAP 五星；NVH、可靠性、舒适性、疲劳耐久、刚强度、门洞密封性、耐腐蚀满足整车性能目标书
    制造与工艺 搭接层次可控（避免 4 层及以上点焊）、涂装可电泳排气、总装可装配、可维修
    成本与轻量化 材料利用率、平台通用化、轻量化、成本控制达标；规避前期车型典型问题
    延续性 硬点可持续迭代，但必须"以已确定的硬点为基础展开"

    示例¶

    以**"碰撞安全满足 C-NCAP 五星"**为例，目标沿两条链分解到底层尺寸：

    分解层级 侧碰链 正碰链
    整车目标 C-NCAP 五星 C-NCAP 五星
    系统目标 侧碰乘员保护（GB 20071-2006：MDB 950 kg / 50 km/h / 90°） 正面碰撞乘员保护（GB 11551-2003：TCFC ≤ 8 kN、TI ≤ 1.3）
    性能指标 B 柱各高度最小断面系数 ZLWR、ZUPR 膝部/小腿保护区域与变形量
    尺寸/结构指标 B 柱钣金截面、加强板布置（如 COROLLA：ZLWR = 1.93×10⁴ mm³、ZUPR = 1.77×10⁴ mm³） 左下护板外表面 X 向变化 ≤ 30 mm；碰撞保护块**最小厚度 30 mm 以上**且平面覆盖 CAE 保护区域

    依据：SJ 54-2009 §4～5、SJ 46-2009 §6.1/§6.4、SJ 21-2008 §5.2.9。

    注意事项¶

    已解析条款中**明确给出的权衡规则只有两条**，其余属于待补充：

    规则一：先协商调整布置方案，再考虑降低指标。 SJ 46-2009 §6.1 的实例——"仪表罩帽檐避光"（要求帽檐盖过反射光线）与"仪表罩与方向盘手操作空间 ≥ 90 mm"两项要求方向相反，规范给出的做法是：在仪表板内部空间允许的条件下，与总体和电气部门协商调整组合仪表的布置，而不是单方面牺牲某一项指标。

    规则二：用降低假人百分位换取舒适性指标达标，但要按既定顺序降级。 QCD-A0-005 §4.2：前排驾驶员与后排乘客尽量考虑 SAE 95% 假人空间；若后排 A44 < 85°，后排改按 SAE 50% 假人；若 50% 假人仍 A44 < 85°，改按 SAE 5% 女性假人。这是显式的降级规则——不允许通过修改角度推荐值来规避。

    待人工补充

    通用权重原则（空间 vs 造型 vs 成本 vs 性能的优先级）：知识库中未见系统性规定， 以上两条只覆盖了"人机内部冲突"与"假人选用"两类具体情形。

    依据：SJ 46-2009 §6.1、QCD-A0-005 §4.2。

    在整车开发中的位置¶

    要点¶

    总布置是**整车开发的"几何总线"**：

    • 向造型输出边界：概念草图阶段就要"对造型提出更具体的边界要求，使后期造型改动量更少， 使后期工程设计更加顺畅"（QCD-A0-005）；
    • 向底盘/车身/电气输出硬点：硬点报告是"后续的底盘、车身、电气等部件的详细设计工作提供了设计依据"；
    • 向下游输出校核清单：造型各阶段（效果图 / CAS / 油泥 / A 面）用固定清单逐项打勾闭环；
    • 是"逆向—对标—正向"的枢纽：知识库中既有竞品车逆向（坐标系建立、H 点确定、样车测量）， 也有标杆车对标（RAV4 / C20 / 宝骏 730 / CS35 / 逸动 与 H20 的断面、搭接、材料对比）。

    示例¶

    项目策划/平台选定 → 概念草图阶段 → 效果图阶段 → CAS/油泥模型 → A面/详细设计 → 硬点冻结 → DMU校验 平台检查 人机工程检查 内/外造型检查 外饰checklist 硬点报告 设计硬点报告 动力总成匹配 整车参数设定 效果图完整性 法规/人机校核 DMU间隙 面向制造/维修 

    ### 2.1 概念草图阶段（平台先行）

QCD-A0-005 的原则是"**概念设计，平台先行**"：先明确市场定位、性能目标、碰撞星级、外廓尺寸区间，
再选定平台与主要配置。

**（1）平台性能检查**
- 整车性能检查：当新车型相对原平台出现 **轴距加长 / 质心抬高（如家轿平台做 SUV）/ 前后轮距变小**
  时，必须预估新车型重量、质心、轴距、轴荷并做仿真，判断平台是否仍然适用；
- 碰撞安全等级检查：目标五星则原平台最好也是五星，否则需大量加强设计与多轮仿真。

**（2）动力总成匹配检查**
- 由整车重量、发动机万有特性、变速箱速比、主减速比、迎风面积（家轿 Cd≈0.27，SUV≈0.3）、
  滚动半径，算出：0→100 km/h 加速时间、最高车速、最大爬坡度、综合工况百公里油耗；
- 与竞争车型对比，有优势才进入布置分析，否则**重新选型**。

**（3）平台布置检查**
- 动力总成布置：碰撞吸能距离 **L1+L2 > 425 mm，L1 > 300 mm，L2 > 50 mm**；
  传动轴角度空/满载轿车 ≤ 5.5°、SUV ≤ 7°；发动机端与纵梁 Y 向间隙 ≥ 25 mm，
  变速箱端 ≥ 20 mm（在纵梁下端）/ ≥ 25 mm（在纵梁内侧）；
- 发动机舱布置：按**温度场**定位大件——蓄电池工作 -30~80 ℃（周边留 10~20 mm 散热间隙）、
  转向机与排气件最小间隙 ≥ 60 mm、ABS/ESP 环境温度 ≤ 120 ℃、引气口温度 ≤ 40 ℃（理想 25 ℃）、
  电器盒 -40~80 ℃、冷却液壶/转向液壶最低液面须为系统最高点；
- 地板下部件：排气管最低点不低于最小离地间隙；油箱续航 ≥ 500 km 且不得为最低点，
  排气管与油箱间隙 > 50 mm；隐藏式排气需 95% 假人在车后 10 m 看不见排气口。

**（4）人机工程检查**（详见第四章）
- 视野系统：下视野轿车 > 6°、SUV > 6.5°；上视野轿车 > 15°、SUV > 16°；A 柱障碍角 GB 11562
  要求 < 6°，**建议设计 < 4.5°**；
- 乘坐舒适性：给出 **H30 = 220~350 mm、A40 = 22~28°、A42 = 85~105°、A44 = 110~125°、A46 = 87°±2**；
  并按车型分级给出 H30 推荐区间（轿跑 220-240 / B 级 230-270 / A 级 280-310 / A0 级 300-330 /
  A00 级 320-350 / SUV 320-350）；
- 操作方便性：换挡手柄包络与手刹包络必须落在驾驶员手握式手伸及界面内（推荐 Ramsis 校核
  95%/50%/5% 假人的不舒适度并对比竞品）；三踏板尺寸（PW1 > 40，PW11 = 60~80，
  PW12 = 70~80，PW13 = 80~120，PW7 = 155~200，PW8 = 50~80，PW9 = 80~90）；
  转向管柱倾角轿跑 22°-24°、轿车 23°-26°、SUV 25°-28°。

**（5）整车参数设定检查**
- 前悬：由碰撞吸能距离 + 散热器/低速碰前保横梁布置 + 接近角对比得出；
- 轴距：由驾驶室假人布置后的乘坐舒适性对比决定加长/减短；
- 后悬：由备胎布置与离去角决定，**GB 7258 要求乘用车后悬不得大于轴距的 55%**；
- 车高：由轮胎型号 + 假人姿态 + 头部空间 + 顶盖典型截面确定；
- 车宽：由 H 点 Y 坐标差与轮距变化推出；
- 接近角/离去角/纵向通过角/最小离地间隙：**以竞争车型数值为设定基准**；
- 轴荷：**GB 7258 要求空载和满载下转向轮轴荷 ≥ 整车整备质量和整车总质量的 30%**。

### 2.2 效果图阶段

依据 **QCD-A0-006 效果图阶段总布置检查规范**（适用于 GB/T 15089 规定的 M、N 类车）：

- **效果图构成**：
  - 外效果图 = 正视图、侧视图、后视图、前 45° 视图（含但不限于）；
  - 内效果图 = 内部侧视图、仪表台视图、座椅视图、门护板视图、副仪表板视图等。
- **检查四类**：
  1. **完整性与配置**：视图完整、车型功能件无缺失、前期配置表得到体现；
  2. **外廓检查**：长/宽/高/轴距/前悬/后悬/轮距/接近角/离去角/最小离地间隙/机舱盖轮廓、
     前后端离地高度（台阶保护 + 法规）、外部照明装置、号牌板位置、外后视镜宽度；
  3. **内部检查**：分块合理性、人体布置空间、座椅尺寸、座间距、驾驶员视野、三踏板间距、
     手操纵件舒适性、方向盘位置及尺寸、仪表板边界、门护板边界、顶棚下边界；
  4. **主要配置**：配置的体现。

### 2.3 造型阶段（效果图 → CAS → 油泥 → A 面）

用 **EDD-A0-005-1 外造型总布置检查清单** 与 **EDD-A0-005-2 内造型总布置检查清单** 逐阶段打勾
（● 完整检查 / ⊙ 局部检查更新），并保留"结论 + 图片示意"两列做证据留痕。

**外造型清单覆盖**：零部件信息完整性（前雨刮、洗涤喷嘴、标徽、拖车钩、牌照板、车顶加强筋、灯具、
后视镜、天线、行李架、加油口盖、门把手、三角窗、上车踏板、挡泥板、倒车雷达、LOGO、排气管、后雨刮、
防滚架等）；整车尺寸（L103 长、H100 高、L101 轴距、L104 前悬、L105 后悬）；通过性（A106-1/2 满载
接近/离去角、A147 通过角、最小离地间隙、裙边离地高、台阶保护高度）；人机（前后上下视野、外开手柄
离地高度与尺寸、门锁离地高、车门宽高、加油口盖离地高、侧门踏板离地高）；法规功能（前机盖距前保距离、
引擎盖开启角度与检修、后备门距后保距离、前后护轮板与轮胎间距及开口大小、前后保险杠低速碰撞、
灯具位置法规校核、备用件）；以及"沿用件 / 借用件"管理。

**内造型清单覆盖**：配置检查、法规项检查、乘坐舒适性（座椅客观尺寸、扶手、内部空间：头/肩/肘/臀/腿/脚）、
操纵舒适性、人机项检查（视野安全性、储物空间实用性、空调出风口可行性、乘员侧方安全距离、膝部保护）、
系统布置可行性（仪表板系统 CCB/风管/HVAC/DVD 与空调控制器/PAB/总成安装；副仪表板系统；门护板与
侧围护板；座椅系统含 SAB 与滑轨；顶棚系统含天窗与 CAB；后备箱区域装备胎/工具/衣帽架）。

### 2.4 详细设计与硬点冻结

进入三维详细设计后，主线交付物是 **《整车总布置设计硬点报告》**，其目录结构本身就是详细设计的
工作分解（H20 实例）：
    1 概述 2 整车设计基准 2.1 整车坐标系 2.2 整车设计状态 3 整车设计硬点 3.1 整车装备选型 3.2 发动机参数 3.3 底盘系统布置主要硬点 3.4 整车性能 3.5 整车质量相关参数 3.6 整车外廓尺寸参数 3.7 车身主要总成控制硬点 3.8 人机工程布置设计硬点 4 结束语 ```

    整车设计基准（H20 定义）： - 坐标系采用**右手坐标系**，与 CATIA 中零部件（part 文件）的绝对坐标系重合； - 高度方向：取前纵梁下平面平直段，上正下负； - 宽度方向：取纵向对称中心线，以汽车前进方向左负右正； - 长度方向：取**整备质量状态**下前轮中心的铅垂线，前负后正； - 设计状态 = 整备质量状态；空载、空载+前排乘员、半载、满载作为校核状态； - 布置时**车身放平（前纵梁平直部分水平）并作为不动基准**，车轮位置由悬架状态拟合出不同地面， 从而得到各载荷状态的整车姿态。

    车身主要总成控制硬点（H20 实例，用于约束上车体）：前/后风窗玻璃倾角、前/后侧窗玻璃倾角、 前/后车门开启角度（一级/二级开度）、发动机盖工作开启角（半锁角/撑杆支撑角）、后背门最大开启角、 外后视镜本体旋转角、加油口盖最大开启角、天窗行程（水平行程 + 开启角）。

    人机工程布置设计硬点（H20 实例）：前排驾驶员/乘员 R 点、二排/三排乘员 R 点坐标；座椅滑轨倾角 A19、水平调节行程 TL17/TL23/TL28、高度调节 TH21/TH22/TH28；靠背后调角与头枕行程；各排人体坐姿 （A46 足角 / A44 膝角 / A42 臀角 / A40 靠背角）；方向盘 A17/A18 倾角与 W9 直径、方向盘中心点； 各排踵点坐标；加速/制动/离合踏板中心点；换挡与驻车手柄受力点；L48 膝部空间、L50 排间 R 点距离、 L11/H17 方向盘中心至踵点水平/垂直距离、L22、H74；H30 各排坐高、L53 H 点至踵点水平距离； H61 各排有效头部空间、W3 肩部、W5 臀部、W31 肘部、H35/W35/W27 头部竖向/横向/斜向空间 （尺寸代码全部参照 SAE J1100-2009）。

    注意事项¶

    （1）造型协同的节奏是"清单式逐阶段闭环"

    EDD-A0-005-1（外造型）与 EDD-A0-005-2（内造型）两张检查清单都以 效果图 / CAS / 油泥模型 / A面 四列作为检查阶段，用 ●（完整检查）/ ⊙（局部检查更新） 标记检查强度，并要求保留"结论 + 图片示意"两列做证据留痕。

    （2）工程反馈必须早于油泥与 A 面

    SJ 40-2009 §4 明确 SEG 阶段的立场是"工程应该尽可能去满足造型的要求"，但其价值在于**提前给出可行边界**——"SEG 分析的好坏直接影响到后期模型的制作进度和工程设计的进度及质量"。油泥模型评审通过后再做 CLASS-A，此时再改代价急剧上升。

    （3）间隙/段差/圆角的发布需要造型确认

    SJ 45-2009 §6.3：效果图冻结后定义**外观可见特征**的间隙、段差、圆角，"在经过造型师的确认之后，进行发布，指导造型进行第二版 CAS 工作和油泥模型工作的展开"。

    （4）与工程（结构设计）的衔接是"断面驱动 + 迭代收敛"

    SJ 4-2008 §3：以主断面为依据进行三维结构设计时，会发现结构不合理、难以实现的问题，反过来修改断面数据；通过反复修改二者的相互关系，最终形成**匹配协调的最终主断面**。

    （5）交付语言要统一

    断面须遵循统一模板与线型规范（SJ 40-2009 §5：尺寸标注 SSS1 字体 3.5 号、基准线 4 号单点划线、假想示意线 5 号双点划线、孔的连接线 2 号虚线、断面线及标注 1 号细线、涂胶 Hatching/45°/Pitch 1mm），并建议采用英文命名——统一语言是跨专业衔接的前提。
