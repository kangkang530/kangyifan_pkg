# 学习资源

## 概述

本章整理汽车总布置相关的学习资源，包括书籍、课程、标准、网站和社区，帮助系统学习和持续提升。

## 学习路径建议

### 在校学生

```mermaid
graph TD
    A[大一/大二] --> B[汽车构造<br/>汽车理论]
    B --> C[大三<br/>汽车设计<br/>CATIA]
    C --> D[大四<br/>毕业设计<br/>实习]
    D --> E[求职<br/>总布置岗位]
```

| 阶段 | 重点 |
|------|------|
| 大一大二 | 基础理论（高数、力学、汽车构造） |
| 大三 | 专业课（汽车设计）+ CATIA |
| 大四 | 毕设实践 + 实习 |
| 研究生 | 深入某一方向（底盘/动力/车身） |

### 转行/自学者

```mermaid
graph TD
    A[基础] --> B[汽车构造<br/>汽车理论]
    B --> C[总布置基础]
    C --> D[CATIA 学习]
    D --> E[系统知识<br/>动力/底盘/车身]
    E --> F[项目实践]
    F --> G[求职准备]
```

| 阶段 | 时间 | 重点 |
|------|------|------|
| 1. 基础 | 1-2 月 | 汽车构造、基本概念 |
| 2. 总布置 | 1 月 | 总布置基础（本知识库） |
| 3. CATIA | 2-3 月 | 建模、装配、DMU |
| 4. 系统知识 | 2-3 月 | 各系统布置 |
| 5. 实践 | 1-2 月 | 临摹布置方案 |
| 6. 求职 | - | 简历、面试准备 |

## 实践建议

### 1. 建立知识体系

```
知识体系框架：
├── 理论基础（汽车理论/构造）
├── 总布置方法（本知识库）
├── 系统知识（动力/底盘/车身/电气）
├── 工具技能（CATIA/DMU/Excel）
├── 法规标准（GB/SAE/ISO）
└── 实践经验（项目积累）
```

### 2. 多看多练

| 实践 | 说明 |
|------|------|
| 拆车看 | 拆解报告、实车参观 |
| 画图练 | CATIA 练习 |
| 参数算 | 轴荷/质心计算 |
| 方案做 | 尝试做布置方案 |

### 3. 持续更新

```mermaid
graph LR
    A[技术发展] --> B[电动化]
    A --> C[智能化]
    A --> D[新材料]
    A --> E[新工艺]
    
    B --> B1[800V/CTB/固态电池]
    C --> C1[线控/域控/自动驾驶]
    D --> D1[碳纤维/铝合金]
    E --> E1[一体化压铸]
```

!!! tip "保持学习"
    汽车技术发展迅速，需持续关注：
    - 新车型发布（关注技术亮点）
    - 行业展会（北京/上海车展、CES）
    - 技术论文（SAE/IEEE）
    - 行业新闻
