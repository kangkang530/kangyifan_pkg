# 关于本知识库

## 项目简介

**汽车总布置知识库** 是一个面向汽车设计与总布置方向的系统性知识整理项目。

### 建站初衷

> 把散落在课本、论文、标准、项目经验里的总布置知识，系统化地整理到一个地方，
> 既是对自己学习的总结输出，也希望帮助后来者少走弯路。

### 目标读者

| 人群 | 阅读建议 |
|------|----------|
| 在校学生 | 从「总布置基础」开始，建立体系认知 |
| 初级工程师 | 重点看「整车参数」与各系统布置，结合实际工作 |
| 转行/自学者 | 通读全部内容，配合案例理解 |
| 资深工程师 | 按需查阅，欢迎补充纠错 |

### 技术栈

- **站点生成器**：MkDocs（Python 静态站点生成器）
- **主题**：Material for MkDocs
- **内容格式**：Markdown
- **版本管理**：Git
- **部署方案**：GitHub Pages / 本地 / 云服务器

选择 MkDocs 而非 Hugo/Jekyll 的原因：

1. **Python 生态**：后期可无缝扩展为 Python Web 应用（Flask/FastAPI）
2. **配置简单**：一个 `mkdocs.yml` 搞定全部配置
3. **Material 主题**：开箱即用的搜索、暗色模式、响应式设计
4. **插件丰富**：支持 Git 修订日期、图表、数学公式等

### 内容来源

- 公开教材与专业书籍

- SAE / ISO 等国际标准

- 公开技术论文与行业报告
